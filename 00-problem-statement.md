# Problem Statement (Frozen)

Main ek AI-native textbook bana rahi hoon jo Physical AI & Humanoid Robotics sikhata hai.

Is textbook mein:
- Structured course content hoga (ROS 2, Gazebo, NVIDIA Isaac, VLA)
- Ek embedded RAG-based AI chatbot hoga jo sirf book ke content se jawab dega
- Logged-in users ke liye content personalization hogi (background ke mutabiq)
- Chapters ko Urdu mein translate karne ka option hoga

Scope explicitly limited hai:
- Real robot control is project ka hissa nahi
- Hardware drivers aur ROS execution implement nahi kiye jaenge
- Focus sirf educational content, AI agents aur system architecture par hoga

Ye problem statement is project ke liye final aur frozen hai.
Iske baad hone wali har implementation isi document ke mutabiq hogi.
